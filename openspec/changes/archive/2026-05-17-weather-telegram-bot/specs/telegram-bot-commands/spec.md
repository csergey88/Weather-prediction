## ADDED Requirements

### Requirement: /start command
Бот SHALL отвечать на `/start` приветственным сообщением и кнопками быстрого доступа.

#### Scenario: Первый запуск
- **WHEN** пользователь отправляет `/start`
- **THEN** бот отвечает приветствием и inline-клавиатурой с кнопками "Погода" и "Прогноз"

### Requirement: /weather command
Бот SHALL возвращать карточку текущей погоды по названию города или сохранённой геолокации.

#### Scenario: Запрос с названием города
- **WHEN** пользователь отправляет `/weather Москва`
- **THEN** бот отвечает карточкой погоды для Москвы с inline-кнопками [Прогноз 3д] [Прогноз 7д] [Обновить]

#### Scenario: Запрос без аргумента с сохранённой локацией
- **WHEN** пользователь отправляет `/weather` без аргумента и у него есть сохранённая локация
- **THEN** бот возвращает погоду для сохранённой локации

#### Scenario: Запрос без аргумента без локации
- **WHEN** пользователь отправляет `/weather` без аргумента и локация не сохранена
- **THEN** бот просит ввести название города

#### Scenario: Неизвестный город
- **WHEN** пользователь отправляет `/weather xyzabc123`
- **THEN** бот отвечает "Город не найден. Уточните название или отправьте геолокацию."

### Requirement: /forecast command
Бот SHALL возвращать прогноз на N дней (1–7, default 3).

#### Scenario: Прогноз на 5 дней
- **WHEN** пользователь отправляет `/forecast Лондон 5`
- **THEN** бот отвечает прогнозом на 5 дней для Лондона

#### Scenario: Превышение лимита дней
- **WHEN** пользователь отправляет `/forecast Москва 10`
- **THEN** бот возвращает прогноз на 7 дней (clamp к максимуму)

### Requirement: /set_location command
Бот SHALL сохранять геолокацию пользователя через FSM-диалог.

#### Scenario: Успешное сохранение
- **WHEN** пользователь отправляет `/set_location`, затем шарит геолокацию
- **THEN** бот сохраняет координаты и отвечает "Сохранено: <Город> (<lat>, <lon>)"

### Requirement: /sources command
Бот SHALL показывать статус всех 4 источников.

#### Scenario: Все источники доступны
- **WHEN** пользователь отправляет `/sources`
- **THEN** бот отвечает списком: OWM ✓ WA ✓ ACW ✓ OM ✓ с весами

### Requirement: /help command
Бот SHALL показывать список всех команд с описаниями.

#### Scenario: Вызов помощи
- **WHEN** пользователь отправляет `/help`
- **THEN** бот отвечает полным списком команд
