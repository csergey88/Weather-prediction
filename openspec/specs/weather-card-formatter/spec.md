## ADDED Requirements

### Requirement: Карточка текущей погоды
Форматтер SHALL генерировать Markdown-карточку из `AggregatedWeather` по шаблону из SPEC.md.

#### Scenario: Полные данные
- **WHEN** передаётся `AggregatedWeather` со всеми полями
- **THEN** карточка содержит: город, дату/время, температуру, ощущаемую, влажность, ветер, видимость, осадки, облачность, confidence-бар, статус источников, время обновления

#### Scenario: Отсутствует visibility
- **WHEN** `visibility_km` равен `None`
- **THEN** поле "Видимость" не отображается в карточке

### Requirement: Карточка прогноза
Форматтер SHALL генерировать компактную Markdown-таблицу прогноза из `list[ForecastPoint]`.

#### Scenario: Прогноз на 3 дня
- **WHEN** передаётся список из 3 `ForecastPoint`
- **THEN** каждая строка содержит: дату, emoji условия, мин/макс температуру, вероятность осадков, скорость ветра

### Requirement: Confidence bar
Форматтер SHALL отображать confidence как текстовый прогресс-бар (████░ 82%).

#### Scenario: Высокая уверенность
- **WHEN** `confidence = 0.9`
- **THEN** бар содержит 4–5 заполненных блоков из 5

#### Scenario: Низкая уверенность
- **WHEN** `confidence = 0.3`
- **THEN** бар содержит 1–2 заполненных блока из 5
